# vocabulary

Names and their meaning in the project. Use them exactly as written.

| Name         | Kind            | Meaning                                                                 |
| ------------ | --------------- | ----------------------------------------------------------------------- |
| imgctl       | System in scope | Shows images to the user when the AI agent asks for it.            |
| User         | Person          | Works in the terminal with an AI agent and looks at the images it shows. |
| AI agent     | External system | Terminal AI agent, such as Claude Code, that asks imgctl to show images. |
| Image viewer | External system | Program that renders the images, such as Okular.                         |
